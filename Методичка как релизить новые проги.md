# Методичка и релиз

Ниже — короткая инструкция, как повторить весь процесс и выпускать обновления.

## Структура проекта
Файлы:
- `index.html`
- `styles.css`
- `app.js`

Папка:

## Подключение Supabase
В `app.js` должны быть актуальные значения:

```js
const SUPABASE_URL = 'https://<project>.supabase.co';
const SUPABASE_KEY = 'sb_publishable_...';
```

Важно:
- Используем только public/anon key.
- Secret key в браузер не вставлять.

## Создание базы (если с нуля)
Открыть **SQL Editor** в Supabase и выполнить:

```sql
create table if not exists projects (
  id uuid primary key default gen_random_uuid(),
  name text unique not null,
  created_at timestamp with time zone default now()
);

create table if not exists tasks (
  id uuid primary key default gen_random_uuid(),
  project text not null,
  task text not null,
  assignee text not null,
  column_id text not null,
  sort_index integer not null default 0,
  created_at timestamp with time zone default now(),
  updated_at timestamp with time zone default now()
);
```

## Импорт задач
Если база пустая, в интерфейсе нажать кнопку:
- **«Импортировать задачи»**

Импорт работает в мягком режиме:
- ничего не удаляет,
- добавляет только новые задачи,
- обновляет задачи, если они уже есть в Supabase.

## Быстрый ввод задач
В каждой колонке есть кнопка **“+”**.
- Появляется быстрый ввод задачи.
- Вводишь текст, выбираешь проект, нажимаешь Enter.
- Исполнитель и проект можно отредактировать в карточке позже.

## Алгоритм релиза
1. Проверь локально: открой `index.html` в браузере.
2. Если база пустая — нажми **«Импортировать задачи»**.
3. Публикация на GitHub Pages:
   - Создай/открой репозиторий.
   - Залей `index.html`, `styles.css`, `app.js`.
   - Settings → Pages → Deploy from branch → `main / root`.
4. Открой публичную ссылку и проверь.
5. Разошли ссылку Ане и Лизе.

## Если что-то сломалось
1. Проверь правильность `SUPABASE_URL` и `SUPABASE_KEY`.
2. Убедись, что таблицы `tasks` и `projects` существуют.
3. Если база пустая — снова нажми **«Импортировать задачи»**.
4. Посмотри ошибки в консоли браузера.
